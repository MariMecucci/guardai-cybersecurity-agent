# Entrega do desafio DIO / Santander Cybersecurity

**Desafio:** GuardAI: Agente Inteligente para Cibersegurança e Análise de Vulnerabilidades

**Repositório:** https://github.com/MariMecucci/guardai-cybersecurity-agent

## Descrição sugerida para envio

> Especializei o DIO Agent no papel de mentor de segurança de aplicações, criando a skill `vulnerability-analysis`, a base de conhecimento `security-basics.md` e ajustes de persona e `AGENTS.md`. Desenvolvi um laboratório local Python/SQLite que demonstra SQL Injection por concatenação de entradas e sua mitigação com consultas parametrizadas, acompanhado de três testes automatizados aprovados. Documentei avaliação de risco, recomendações defensivas e a validação inicial do agente pelo GitHub Copilot no VS Code, incluindo perguntas de contexto e autorização, leitura dos arquivos e análise inicial do código. A implementação utiliza exclusivamente dados fictícios, em ambiente controlado.
